# Soft Loops by SA 🧶

A single-page catalog website for a handmade crochet business. Customers browse the products and order directly on WhatsApp.

🌐 **Live:** [softloops-by-sa.netlify.app](https://softloops-by-sa.netlify.app/)

## Features
- Full-screen hero with brand name and tagline
- Product grid with an "Order on WhatsApp" button (message pre-filled)
- About and Contact sections
- Mobile-first, responsive design

## Built With
React · Vite · Tailwind CSS · Netlify

## Run Locally
```bash
git clone https://github.com/zainab-reactdev/Softloops-By-SA.git
cd Softloops-By-SA
npm install
npm run dev
```

## Customize
Edit the constants and the `products` array at the top of `src/App.jsx`. Product photos go in `public/images/`.
